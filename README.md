## Updating Nino

In Nino, open **Settings → App updates → Check for updates**. When the published patch manifests provide a complete route from your installed version to the latest build, Nino downloads the required patches and applies them in one update session.

If Nino says no complete update path is available, download the latest installer above and run it over your existing installation. Leave **Clean install** unchecked to keep saved Nino data. Back up important data before testing prerelease builds.

## What Nino can do

- Chat with character companions and configure their profiles, themes, greetings, and preferences.
- Use live voice calls with microphone and speaker selection, hands-free or push-to-talk modes, and subtitles.
- Keep Nino nearby in a desktop companion window, with 2D and 3D modes, VRM avatars, scenes, animations, and expressions.
- Use Nino's phone-style interface for messages, calls, notebook, clock, browser, social feed, and settings.
- Configure AI and voice providers. Provider credentials and network access may be required; optional voice packs are published separately.
- Extend Nino with remote OAuth-connected MCP plugins or consent-based local tools, with per-tool controls.

Paid character profile packs are not bundled with the public installer.

## Before installing

- Nino Desktop is currently a **Windows x64 beta**. Expect bugs and changes between releases.
- The installer is unsigned, so Windows may show an unknown-publisher warning.
- The packaged app requires a valid one-device license.
- Some AI and voice features require accounts, provider credentials, or network access.
