## What Nino can do

### Your companion, your way

- Chat with character companions with distinct profiles, personalities, voices, and profile pictures.
- Switch the active companion and carry her identity across the avatar, desktop pet, voice, and character theme.
- Open a character profile to see her portrait, last-active status, voice, desktop pet, and personality details.
- Customize the phone and desktop with default app themes or character-specific themes.

Paid character profile packs are **not bundled** with the public installer. You can add supported profiles separately.

### Chat and voice

- Have one-to-one conversations or create group chats, with messages attributed to the character who said them.
- Adjust chat details, clear an individual chat, and control optional check-ins.
- Use live voice calls with microphone and speaker selection, hands-free or push-to-talk mode, and on-screen subtitles.
- Choose AI and voice providers in settings. Optional voice packs are published separately.

### Desktop companion

- Keep Nino nearby in a desktop companion window, with 2D and 3D Open Space modes.
- Use VRM avatars, scenes, backgrounds, animations, expressions, and character-specific desktop pets.
- Open compact chat, subtitles, and companion controls while using other desktop apps.
- Match the companion interface and loading screen to the selected theme.

### Nino's phone

The phone interface is a compact home for Nino's apps. Arrange apps in a 3 × 3 grid, drag apps into the four-icon quick bar, and reorder the quick bar.

- **Messages** — manage individual and group conversations.
- **Call** — open the live call screen and audio controls.
- **Notebook** — save notes, ideas, and plans.
- **Clock** — view the time and create alarms with repeat-day selection and custom alarm sounds.
- **Browser** — use tabs, private browsing, history, and bookmarks in a phone-sized view.
- **Ninoverse** — access Nino's social feed.
- **Settings** — customize the companion, themes, voice, providers, and app behavior.

Regular browser tabs and bookmarks persist between sessions. Private tabs are kept separate and are not saved between sessions. Some websites restrict embedded browsers or choose their own layout.

### Personalization, tools, and privacy

- Select character themes or default themes; the selected colors carry through the phone, desktop companion UI, subtitles, and compact chat.
- Configure character voice, greetings, scenes, idle animation, and reply preferences.
- Use the soundboard, accessibility shortcuts, text sizing, and high-contrast keyboard focus.
- Review and manage Nino's memories and privacy settings.
- Extend Nino with remote OAuth-connected MCP plugins or consent-based local tools, with per-tool controls.

## Where we're headed

Nino is being developed as a personal, configurable desktop companion that can stay present throughout the day while keeping customization and control in the user's hands.

Our direction includes:

- **More dependable everyday use:** improve startup, updates, calls, microphone setup, and recovery when something goes wrong.
- **Deeper character experiences:** expand profile customization and make each companion's voice, personality, appearance, and behavior feel consistent across the app.
- **A more connected desktop and phone:** keep themes and companion state in sync, and continue refining the small-screen apps and desktop controls.
- **More expressive voice and avatars:** improve conversational voice, animation, and VRM support while keeping provider choices configurable.
- **Useful integrations with clear controls:** grow the plugin ecosystem with visible permissions and privacy settings.

This is a direction, not a release schedule. Features and priorities may change as beta feedback comes in.

## Before installing

- Nino Desktop is currently a **Windows x64 beta**. Expect bugs and changes between releases.
- The installer is unsigned; Windows may show an unknown-publisher warning.
- A valid one-device license is required by the packaged app.
- Some features use the AI or voice provider you choose. Network access and provider credentials may be required.
- Optional GPT-SoVITS weights are distributed in the separate [Nino Voice Packs release](https://github.com/JIM50051/Nino-Public-Releases/releases/tag/nino-voice-packs).
